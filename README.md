# ARABIC NEXT STEPS

**Teacher Report Comment Generator | مولّد تعليقات تقارير الطلاب**

A bilingual React and TypeScript platform for Arabic A and Arabic B teachers to review curriculum-aligned Next Steps descriptors, select exactly three comments, preview them in one report box, and copy them together in the required point-form format.

## Features

- Arabic A for Grades 6–12 and Arabic B for Grades 6–10
- Seven differentiated proficiency levels
- Criterion and proficiency filters with English and Arabic keyword search
- English descriptors with Arabic reference translations
- One unified report box containing exactly three comments
- One copy action using an en dash and space, infinitive openings, and no trailing full stops
- Automatic descriptor-format checks in the teacher and administrator workflows
- Personal favourites saved locally
- Department Head administration with local passphrase hashing
- Comment approval, rejection, editing, deletion, CSV import/export, and audit logging
- Responsive LTR and RTL layouts

## Technology

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Lucide React

The current version stores comment-bank changes, favourites, and audit entries in the browser's local storage. Administrator credentials are created locally by the Department Head; no password is hardcoded in the source. This browser-only mode does not provide server-side authentication or a shared school database.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

The generated site is written to `dist/`.

## Report output rules

The report output is generated by `formatThreeCommentsForReport` in `src/utils/clipboard.ts`:

- Exactly three unique, approved, format-compliant comments are required
- Each comment starts with `– ` and an infinitive verb
- Comments appear together in one text box, each on its own line
- No Arabic translation, heading, trailing full stop, or unrelated text is added

## GitHub Pages deployment

The repository includes `.github/workflows/deploy-pages.yml`. It builds the Vite application and deploys `dist/` to GitHub Pages. The workflow supports both a project in the repository root and the current nested `Teacher-Report-Comment-Generator` folder.

1. Ensure `.github/workflows/deploy-pages.yml` is present at the **repository root**.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions** (not a branch).
4. Open **Actions**, wait for **Deploy Arabic Next Steps to GitHub Pages** to complete, then run it again with **Run workflow** if necessary.

## Project structure

- `src/data/` — curriculum configuration and bilingual descriptor bank
- `src/components/` — dashboard, generator, report box, favourites, and administration views
- `src/utils/clipboard.ts` — descriptor validation, report formatting, and clipboard handling
- `src/utils/storage.ts` — local persistence, administrator authentication helpers, CSV import/export
- `src/types/` — shared curriculum and application types
- `public/images/` — educational imagery

## Academic integrity

Descriptors are labelled as curriculum-aligned platform adaptations unless explicitly classified otherwise. The seven proficiency levels are an internal platform classification, not official UAE Ministry of Education or IB proficiency labels. Pending and rejected descriptors are not published in the teacher comment generator.
